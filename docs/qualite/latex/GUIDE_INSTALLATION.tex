Ce guide permet à un tiers de reproduire l\textquotesingle installation
et \textbf{toutes les couches de test} sur sa machine. Les résultats
sont écrits dans \texttt{quality/reports/}. Vérifié sous Windows 11 (Git
Bash + Docker Desktop) ; la CI le reproduit sous Linux (Ubuntu, GitHub
Actions).

\section{4. Limites connues de l\textquotesingle environnement (règle
d\textquotesingle or du cahier des
charges)}\label{4-limites-connues-de-lenvironnement-ruxe8gle-dor-du-cahier-des-charges}

\begin{itemize}
\tightlist
\item
  \textbf{Firefox (Playwright)} : le binaire Firefox téléchargé par
  Playwright ne démarre pas sur le poste Windows de
  l\textquotesingle équipe (\texttt{spawn\ UNKNOWN} : exécutable bloqué
  par le système). Il est désactivé par défaut ; pour
  l\textquotesingle exécuter sur une autre machine :
  \texttt{PW\_}\allowbreak{}\texttt{FIREFOX=1\ npx\ playwright\ test}.
  La compatibilité est prouvée sur Chromium, Microsoft Edge, WebKit
  (moteur de Safari) et Chrome mobile (Pixel 7).
\item
  \textbf{Microsoft Edge} : le projet Playwright \texttt{edge} utilise
  l\textquotesingle Edge installé sur la machine ; sous Linux sans Edge,
  lancer
  \texttt{npx\ playwright\ test\ -}\allowbreak{}\texttt{-}\allowbreak{}\texttt{project=chromium\ -}\allowbreak{}\texttt{-}\allowbreak{}\texttt{project=webkit\ -}\allowbreak{}\texttt{-}\allowbreak{}\texttt{project=mobile-}\allowbreak{}\texttt{chrome}.
\item
  \textbf{Réseau d\textquotesingle entreprise avec proxy TLS} :
  \texttt{npm\ audit} peut échouer
  (\texttt{unable\ to\ verify\ the\ first\ certificate}) ; utiliser
  \texttt{NODE\_}\allowbreak{}\texttt{OPTIONS=-}\allowbreak{}\texttt{-}\allowbreak{}\texttt{use-}\allowbreak{}\texttt{system-}\allowbreak{}\texttt{ca\ npm\ audit\ -}\allowbreak{}\texttt{-}\allowbreak{}\texttt{omit=dev}.
\item
  \textbf{Limitation des connexions} : la connexion et
  l\textquotesingle inscription sont limitées à 10 requêtes / 5 min /
  IP. Enchaîner plusieurs campagnes de tests à la suite peut donner des
  429 ; attendre 5 minutes ou utiliser le script (qui relève la limite
  le temps de la campagne API seulement).
\end{itemize}
