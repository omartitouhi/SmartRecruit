\section{6.3 Compatibilité}\label{63-compatibilituxe9}

\textbf{Exigence} : fonctionnement sur au moins 2 navigateurs et
coexistence avec un système tiers.

\begin{itemize}
\tightlist
\item
  \textbf{Multi-navigateurs} : la même suite Playwright tourne sur
  \textbf{Chromium}, \textbf{Microsoft Edge 157} (installé),
  \textbf{WebKit} (moteur de Safari) et \textbf{Chrome mobile}
  (émulation Pixel 7, écran tactile). Résultat : 62/62 (les 6 tests
  d\textquotesingle accessibilité ne tournent que sur Chromium). Preuve
  :
  \texttt{quality/}\allowbreak{}\texttt{reports/}\allowbreak{}\texttt{e2e-}\allowbreak{}\texttt{ui/}\allowbreak{}\texttt{html/}\allowbreak{}\texttt{index.}\allowbreak{}\texttt{html}
  (colonne projet).
\item
  \textbf{Firefox} : le binaire Firefox de Playwright ne démarre pas sur
  le poste Windows de l\textquotesingle équipe
  (\texttt{browser}\allowbreak{}\texttt{Type.}\allowbreak{}\texttt{launch:\ spawn\ }\allowbreak{}\texttt{UNKNOWN},
  exécutable bloqué par le système). Conformément à la règle
  d\textquotesingle or, il est \textbf{documenté comme non exécutable}
  et non simulé ; procédure pour une autre machine :
  \texttt{PW\_}\allowbreak{}\texttt{FIREFOX=1\ npx\ playwright\ test}.
\item
  \textbf{Coexistence avec un système tiers} : le service IA appelle un
  LLM externe (OpenRouter, API compatible OpenAI) quand
  \texttt{AI\_ENGINE=llm}, et bascule sur un moteur à règles local
  sinon.
  \texttt{ai-}\allowbreak{}\texttt{service/}\allowbreak{}\texttt{tests/}\allowbreak{}\texttt{test\_}\allowbreak{}\texttt{llm\_}\allowbreak{}\texttt{client.}\allowbreak{}\texttt{py}
  vérifie le contrat avec l\textquotesingle API externe (réponse JSON
  validée par schéma, réponse non conforme, échec ou délai dépassé →
  erreur contrôlée) et \texttt{test\_skill\_gap.py} la traduction en
  502/503 pour l\textquotesingle appelant. Le contrat
  d\textquotesingle API REST est vérifié par les 155 vérifications API
  (codes HTTP et structure JSON).
\end{itemize}
