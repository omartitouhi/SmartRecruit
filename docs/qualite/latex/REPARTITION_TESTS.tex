\section{Règles communes}\label{ruxe8gles-communes}

\begin{itemize}
\tightlist
\item
  \textbf{Règle d\textquotesingle or} : aucun résultat sans exécution
  réelle ; après chaque ré-exécution, mettre à jour la ligne
  correspondante de la matrice et du
  \href{RAPPORT_CONFORMITE_ISO25010.pdf}{rapport de conformité}. Un
  outil qui ne s\textquotesingle exécute pas sur le poste est documenté
  comme tel (procédure + « résultat non disponible »).
\item
  Avant la soutenance, un membre lance la campagne complète
  \texttt{bash\ quality/}\allowbreak{}\texttt{run-}\allowbreak{}\texttt{all.}\allowbreak{}\texttt{sh}
  et archive la sortie dans
  \texttt{quality/}\allowbreak{}\texttt{reports/}\allowbreak{}\texttt{campagne-}\allowbreak{}\texttt{finale-}\allowbreak{}\texttt{console.}\allowbreak{}\texttt{txt}.
\item
  Chaque membre relit les tests d\textquotesingle un autre (1→2→3→4→1)
  pour qu\textquotesingle aucune couche n\textquotesingle ait un seul
  regard.
\end{itemize}
