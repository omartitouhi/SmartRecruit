(base neuve à chaque test). Le vrai PostgreSQL est couvert par les 155
tests API sur la stack Docker complète. \\
Combien de tests ? & 693 JUnit (6 services) + 137 pytest (IA) + 403
Vitest (front) = 1 233 ; 155/155 vérifications API. Preuve :
\texttt{quality/}\allowbreak{}\texttt{reports/}\allowbreak{}\texttt{unit/}\allowbreak{},

Montrez une règle métier et son test. & RG‑03 :
